这项评价如何计算

每次只展开能降低向听数的摸牌，以该牌未见张数除以全部未见张数加权；摸走一张后更新牌数。14 张在最低向听的出牌中取最高值。达到起胡门槛时，胡牌评价为 2 的 max（番数，1）次方，按普通自摸计番。

分数用于比较连续进张路线。当前不计无效摸牌后的等待收益、退向听和对手行动；可用张数为 0 的空听仍会展示分组。较复杂的牌型可继续分析，复用已完成的缓存。
